📖 Task List Manager - How to Use

Learn about all the features and best practices

🚀 Getting Started

The Task List Manager helps you organize and track your tasks efficiently with features like subtasks, priorities, completion tracking, and multiple backup options.

💡 Tip: All your tasks are automatically saved to your browser's local storage, so they persist between sessions!

✅ Managing Tasks

Adding a Task

  1. Enter a task title in the "Task Title" field
  2. Add a description in the "Task Description" field (optional)
  3. Select a priority level (Urgent, High, Medium, Low)
  4. Choose a category (Work, Personal, Shopping, Health, Other)
  5. Click "Add Task" button

Task Actions

✓ Complete/Uncomplete: Click the checkbox to mark a task as done. The completion date will be automatically added on the right side.
✏️ Edit: Click the pencil icon to edit the task title or description inline.
📦 Archive: Click the archive icon to move tasks to the archive. Archived tasks can be viewed using the "Archived" filter.
🗑️ Delete: Click the trash icon to permanently delete a task (careful - this cannot be undone!).

📋 Working with Subtasks

Adding Subtasks

  1. Click "Add Subtask" button on any task
  2. Enter the subtask description
  3. Press Enter or click the add button

Subtask Features

  • Check off subtasks as you complete them - completion dates are tracked
  • Progress bar shows how many subtasks are completed
  • Edit subtasks by clicking the edit icon
  • Delete subtasks with the trash icon
  • Toggle subtask visibility with the "Show/Hide Subtasks" button

🔍 Filtering and Organization

Available Filters

All: Shows all tasks (except archived)
Active: Shows only incomplete tasks
Completed: Shows only completed tasks
🔥 Urgent / ⚡ High / 📌 Medium / 📍 Low: Filter by priority level
📦 Archived: Shows only archived tasks (can be unarchived)

💾 Export and Backup Features

📧 Export for Email

Creates a formatted text summary of your tasks that you can copy and paste into emails or documents. Includes:

  • Task counts and completion statistics
  • Active tasks with subtasks
  • Completed tasks with completion dates
  • Archived tasks (if any)

How to use: Click "📧 Export for Email" → Click "📋 Copy to Clipboard" → Paste anywhere!

💾 Manual Backup

Downloads a complete JSON backup file with timestamp. This is your primary safety net.

  • Creates timestamped files: tasks-backup-2025-11-07.json
  • Save multiple versions for different points in time
  • Store on USB drives, cloud storage, or multiple locations
✅ Best Practice: Create manual backups regularly, especially before major changes or at the end of each week!

📥 Import Tasks

Restore tasks from a backup file. You can choose to:

  • Merge: Add imported tasks to your existing tasks (combines both)
  • Replace: Replace all existing tasks with the backup (careful!)

🔄 Auto-Backup

Automatically saves a single backup file to a folder of your choice.

How Auto-Backup Works:

  1. Click "🔄 Auto-Backup" button (turns green when enabled)
  2. Select a folder where the backup should be saved
  3. Grant permission (one-time only)
  4. The app will automatically save to tasks-auto-backup.json:
    • Every hour
    • When you close the browser
⚠️ Important: Auto-backup overwrites the same file each time. It's meant for convenience, not version history. Always use manual backups for critical safety nets!
💡 Browser Support: Auto-backup only works in Chrome, Edge, and Chromium-based browsers. Firefox and Safari users should rely on manual backups.

💿 Data Storage and Portability

Where Are My Tasks Stored?

Your tasks are saved in your browser's localStorage, which means:

  • ✅ Persists through browser refreshes and computer restarts
  • ✅ Completely private - stays on your computer
  • ✅ No internet connection required
  • ⚠️ Tied to the specific browser on this computer
  • ⚠️ Lost if you clear browser data/cache

Using Tasks on Multiple Computers

  1. On Computer A: Click "💾 Backup Tasks"
  2. Save the file to a USB drive, email it to yourself, or use cloud storage (OneDrive, Dropbox, etc.)
  3. On Computer B: Open the Task List Manager
  4. Click "📥 Import Tasks" and select the backup file
  5. Choose "Replace" for a fresh copy or "Merge" to combine with existing tasks
💡 Pro Tip: Keep your backup files in OneDrive or Google Drive so they're always accessible from any computer!

🎯 Best Practices

Weekly Reviews: Archive completed tasks at the end of each week to keep your active list clean.
Regular Backups: Create manual backups before clearing browser data or making major changes.
Use Priorities: Mark urgent tasks so you can filter and focus on what matters most.
Break Down Big Tasks: Use subtasks to make large projects more manageable.
Archive, Don't Delete: Archive completed tasks instead of deleting them to maintain a history.
Backup Strategy: Use auto-backup for convenience + manual backups for safety.

🔧 Troubleshooting

Tasks Disappeared After Clearing Browser Data

Unfortunately, if you cleared your browser's cache/localStorage without a backup, the tasks are gone. This is why regular backups are important!

Solution: Import your most recent backup file.

Auto-Backup Button Doesn't Work

This feature requires a Chromium-based browser (Chrome, Edge, Opera).

Solution: Use manual backups if you're on Firefox or Safari.

Can't See Archived Tasks

Archived tasks are hidden by default.

Solution: Click the "📦 Archived" filter button to view them.

Lost Permission for Auto-Backup Folder

Browsers may revoke folder permissions after a while.

Solution: Click "🔄 Auto-Backup" again to re-grant permission.

🔒 Security and Privacy

  • All data stays local: Nothing is uploaded to the internet or any server
  • No tracking: The app doesn't track, monitor, or send any data anywhere
  • Browser security: The app runs in your browser's secure sandbox
  • Auto-backup security: You explicitly grant permission to ONE folder only
  • You're in control: You can disable auto-backup, delete all tasks, or export data anytime
✅ Privacy First: Your tasks are yours alone. No accounts, no cloud sync, no data collection.
