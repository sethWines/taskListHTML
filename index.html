Welcome to Task List Manager!

Choose how you want to store your tasks:

📁

File-Based Storage (Recommended)

  • ✅ Unlimited storage (your hard drive)
  • ✅ Fast & efficient
  • ✅ Easy backup (just copy the file)
  • ✅ No browser storage bloat
  • ✅ Portable between machines

Best for: Heavy users, large task lists, long-term storage

🌐

Browser Storage (localStorage)

  • ✅ Simple setup (no file selection)
  • ✅ Works in any browser
  • ⚠️ Limited to ~5MB storage
  • ⚠️ Shared with other apps/sites
  • ⚠️ Lost if browser data cleared

Best for: Light users, temporary lists, trying the app

💡 Tip: You can change this later in settings. File storage requires Chrome, Edge, or other Chromium-based browsers.
